# 보컬 레슨 플랫폼 화면 목록 — 1단계

- 상태: 초안
- 기준 문서: `docs/prd.md`(PR #2)의 요구사항. 괄호 안의 `HW-02` 같은 ID가 그 화면이 다루는 요구사항이다.
- 표기
  - 화면 ID: `C-` 공통, `S-` 학생, `T-` 트레이너, `A-` 운영자
  - **(제안)**: PRD에 없고 Claude가 채워 넣은 항목. 확인 전까지는 확정이 아니다.
  - **[결정 n]**: 이 문서 끝 "결정 필요" n번과 연결된 항목.
- 이 문서는 화면의 목록과 각 화면에 들어갈 요소·이동만 정한다. 배치와 디자인은 와이어프레임 단계에서 정한다.

## 1. 내비게이션 구조

로그인한 계정의 역할(학생 / 트레이너 / 운영자)에 따라 다른 하단 탭을 보여 준다. 학생 탭은 트레이너 찾기가 추가되면서 다시 정해야 한다. [결정 2]

| 역할 | 하단 탭 |
|---|---|
| 학생 | 홈 · 찾기 · 레슨(숙제·일정) · 채팅 · 내 정보 (제안) |
| 트레이너 | 홈 · 학생 · 일정 · 채팅 · 내 정보 |
| 운영자 | 트레이너 · 신고 · 정산 · 내 정보 |

- 학생은 여러 트레이너에게 배울 수 있으므로, 학생 화면의 목록(숙제, 일정, 수강권)은 모든 트레이너 것을 함께 보여 주고 트레이너별로 거를 수 있다.

## 2. 공통 화면

- **C-01 링크 진입** — 트레이너 프로필 링크를 열면 앱을 연다. 앱이 없으면 스토어 설치 후 그 트레이너의 프로필(S-01)로 이어진다. (TRN-02, NFR-05)
- **C-02 로그인** — 카카오, 구글 로그인 버튼. iOS에는 애플 로그인 버튼도 있다. (AUTH-01)
- **C-03 휴대폰 본인인증** — 가입할 때 한 번. 만 19세 미만이면 가입할 수 없다는 안내를 보여 주고 더 진행하지 않는다. (AUTH-03)
- **C-04 역할 선택** — 링크 없이 앱을 직접 설치해 가입할 때만 나온다. "학생" / "트레이너로 가입 신청" 중 고른다. 링크로 들어온 사람은 이 화면 없이 학생이 된다. (AUTH-02)
- **C-05 프로필 설정** — 닉네임, 프로필 사진. 가입 마지막 단계이고, 나중에 내 정보에서 고칠 수 있다. (AUTH-06)
- **C-06 알림 목록** — 받은 푸시 알림을 모아 보고, 누르면 해당 화면으로 간다. (제안)
- **C-07 설정** — 알림 설정, 문의처, 약관·개인정보 처리방침, 로그아웃, 탈퇴. (AUTH-07, CHAT-07)
- **C-08 탈퇴 확인** — 탈퇴하면 계정 정보와 영상을 약 6개월 보관한 뒤 삭제한다는 안내와 확인 버튼. (AUTH-08)

## 3. 학생 화면

### 합류·결제

- **S-01 트레이너 프로필** — 이름, 사진, 지역, 장르, 경력, 소개글, 레슨 장소, 소개·노래 영상(최대 3개, 눌러서 재생). 레슨 상품 목록(1:1 / 그룹, 정기권 회차별 가격, 일회권 가격, 레슨 길이). 후기 목록(S-22). "문의하기" 버튼(S-21). 상품을 고르면 S-02로 간다. 트레이너 링크와 트레이너 찾기 양쪽에서 들어온다. (TRN-01~09, PAY-02, DM-01)
  - 파일럿 트레이너의 프로필에는 상품과 가격 대신 "시작하기" 버튼만 있다. 가입하면 바로 수강 관계가 생기고 S-03으로 간다. (PLT-02)
  - 로그인하지 않은 상태에서 상품을 고르면 C-02 → C-03 → C-05를 거친 뒤 S-02로 돌아온다.
- **S-02 결제** — 고른 상품, 금액, 유효기간(1년) 확인. 결제 수단(카드, 카카오페이, 네이버페이, 토스페이) 선택과 결제. (PAY-01, PAY-03)
- **S-03 시작 완료** — 수강권 요약. 정기권이면 "트레이너가 일정을 입력하면 알려 드려요"(일정 대기) 안내. 단체 채팅방에 들어갔다는 안내. 홈으로 가기. (PAY-04, PAY-05, CHAT-03)

### 홈

- **S-04 홈** — 다가오는 레슨, 해야 할 숙제(미제출, 마감 임박 순), 새로 온 피드백. 수강권이 1회 남았으면 재결제 배너. (SCH-09, HW-11, PAY-07)
- **S-05 첫 홈 (수강 중인 트레이너 없음)** — 링크 없이 설치해 아직 수강 관계가 없는 학생의 홈. 트레이너 찾기(S-20)로 가는 버튼과, 트레이너에게 받은 링크가 있으면 붙여 넣는 칸. (MKT-01)

### 트레이너 찾기·문의·후기

- **S-20 트레이너 찾기** — 승인된 트레이너 목록. 필터: 지역, 장르, 가격대. 정렬. 각 항목에 사진, 이름, 지역, 장르, 가장 싼 1회당 가격, 후기 수. 누르면 S-01. (MKT-01~05)
- **S-21 1:1 대화** — 트레이너에게 문의하는 대화. 텍스트·사진, 신고, 차단, 알림 끄기. 대화 상단에 그 트레이너의 프로필로 가는 버튼. (DM-01~07)
- **S-22 후기 목록** — 트레이너 프로필에서 들어온다. 후기 글, 작성자 닉네임, 작성일, 트레이너 답글. 후기 신고. (REV-01~06)
- **S-23 후기 쓰기·고치기** — 수강권 상세(S-07)나 지난 레슨에서 들어온다. 글 입력, 등록. 자기 후기는 고치거나 지울 수 있다. (REV-02, REV-04)

### 수강권·환불

- **S-06 수강권 목록** — 트레이너별 수강권. 남은 횟수 / 총 횟수, 유효기간, 상태(일정 대기, 진행 중, 종료). 종료 이유(소진, 만료, 환불)는 상세(S-07)에서 보여 준다. (PAY-03, ATT-05)
- **S-07 수강권 상세** — 고정 일정, 회차별 출결 내역, 재결제 버튼, 환불 요청 버튼. (ATT-05, PAY-07, PAY-10)
- **S-08 환불 요청** — 대상 수강권과 남은 회차 확인, 사유 입력(선택), 요청 보내기. 요청 상태(요청됨 / 처리됨)를 보여 준다. 예상 환불 금액 표시는 환불 금액 규칙(`docs/idea.md` 결정 필요 2)이 정해진 뒤 정한다. (PAY-10)
- **S-09 결제 내역** — 결제와 환불 기록. (제안)

### 일정

- **S-10 일정** — 다가오는 회차와 지난 회차 목록. 트레이너별로 거를 수 있다. (SCH-09)
- **S-11 레슨 회차 상세** — 일시, 장소, 1:1 / 그룹, 출결 상태, 이 회차의 숙제. 취소 버튼은 레슨 시작 24시간 전까지만 누를 수 있고, 그 뒤에는 "24시간 이내에는 취소할 수 없어요" 안내로 바뀐다. (SCH-05, ATT-05)
- **S-12 취소 확인** — "사전 취소는 수강권이 차감되지 않아요" 안내와 확인. (SCH-05, ATT-02)

### 숙제·피드백

- **S-13 숙제 목록** — 미제출 / 제출됨으로 나눠 보여 준다. 마감일, 트레이너. (HW-11)
- **S-14 숙제 상세** — 설명, 예시 영상 재생(있을 때), 마감일, 내 제출 기록 목록, "제출하기" 버튼. (HW-02, HW-07)
- **S-15 연습 영상 제출** — 바로 촬영 / 갤러리에서 고르기, 5분 제한 안내, 질문 입력(선택), 업로드 진행률. 업로드가 끊기면 이어 올린다. (HW-06, HW-08, HW-09, HW-13, NFR-03)
- **S-16 제출 상세** — 내 연습 영상 재생. 재생 바 위에 트레이너의 시점 코멘트 위치가 표시되고, 누르면 그 시점으로 이동한다. 텍스트 코멘트 목록. (HW-10)

### 채팅·내 정보

- **S-17 채팅 목록** — 수강 중인 트레이너별 단체 채팅방과 1:1 대화를 한 목록에 보여 준다. 단체 / 1:1 구분 표시. (CHAT-01, DM-01)
- **S-18 채팅방** — 메시지, 사진 보내기. 메시지 길게 눌러 신고, 사용자 프로필에서 차단. 방 메뉴에서 알림 끄기, 나가기, 참여자 목록(닉네임·사진만). 학생끼리 1:1 대화를 열 수 있는지는 PRD 결정 필요 11. (CHAT-03~08)
- **S-19 내 정보** — 프로필 수정, 수강권 목록(S-06), 결제 내역(S-09), 설정(C-07).

## 4. 트레이너 화면

### 가입·준비

- **T-01 가입 신청** — 본인인증(C-03) 뒤 정산 계좌 입력, 신청 완료. (AUTH-04)
- **T-02 승인 대기 홈** — "운영자 확인 중" 안내. 이 상태에서도 프로필(T-03)과 상품(T-04)을 작성할 수 있고, 프로필 링크는 승인 후에 열린다. (AUTH-05 제안)
- **T-03 프로필 편집** — 이름, 사진, 지역, 장르, 경력, 소개글, 레슨 장소, 소개·노래 영상 올리기(최대 3개, 순서 바꾸기·삭제). 트레이너 찾기 목록 노출 설정은 PRD 결정 필요 9. (TRN-01, TRN-07, TRN-08, MKT-07)
- **T-04 레슨 상품 관리** — 1:1 / 그룹 상품 목록과 편집. 정기권 회차는 4·8·12회 중 선택 또는 직접 입력, 회차별 가격. 일회권 가격. 레슨 길이. (TRN-03, TRN-05, TRN-06)
- **T-05 프로필 링크 공유** — 링크 복사, 카카오톡으로 공유. (TRN-02)

### 홈·학생

- **T-06 홈** — 오늘의 레슨, 출결을 체크하지 않은 회차, 일정 입력이 필요한 학생(일정 대기), 새 숙제 제출, 환불 요청. (ATT-04, PAY-05, PAY-10)
- **T-07 학생 목록** — 수강 중인 학생, 수강권 남은 횟수, 일정 대기 표시, 그룹 반 소속. (제안)
- **T-08 학생 상세** — 수강권들, 고정 일정, 회차별 출결, 숙제 제출 현황. 일정 입력·수정(T-09), 보강 만들기(T-14), 환불 처리(T-20)로 이동. (PAY-08, ATT-05, HW-11)

### 일정·출결

- **T-09 고정 일정 입력·수정** — 요일·시간(여러 요일 가능), 시작일. 파일럿 트레이너는 여기서 수강권 횟수도 입력한다. 수정할 때는 "수정한 시점 이후 회차만 바뀌어요" 안내. 일회권은 날짜·시간 하나만 입력한다. (SCH-01, SCH-02, SCH-04, PLT-03)
- **T-10 그룹 반 관리** — 반 목록, 반 만들기(고정 일정, 정원, 상품), 그룹 수강권을 결제한 학생을 반에 배정. (TRN-04)
- **T-11 일정** — 목록 보기와 주간 캘린더 보기를 전환할 수 있다. 모든 회차를 1:1과 그룹 반 구분과 함께 보여 준다. (SCH-09)
- **T-12 레슨 회차 상세** — 일시, 학생(들), 출결 상태, 이 회차 숙제. 출결 체크(T-13), 숙제 등록(T-15), 일정 변경, 회차 취소로 이동. (SCH-03, SCH-06)
- **T-13 출결 체크** — 학생마다 상태 선택. 사전 취소한 학생은 "사전 취소"로 이미 표시되어 있다. 정산 확정 전까지 고칠 수 있다는 안내. 보강 회차에서는 학생이 오면 "보강", 오지 않으면 "결석"으로 기록한다(둘 다 차감). (ATT-01~03, ATT-06)
- **T-14 보강 만들기** — 남은 회차가 있는 학생 선택, 날짜·시간. 그룹 반 학생도 개별 보강으로 잡는다. (SCH-08)

### 숙제·피드백

- **T-15 숙제 등록** — 대상(그룹 반이면 전체 / 특정 학생 선택), 설명, 예시 영상(새로 촬영 / 갤러리 / 영상 보관함에서 선택, 없어도 됨), 마감일(기본: 다음 레슨 전). 한 회차에 여러 개 등록할 수 있다. (HW-01~05)
- **T-16 영상 보관함** — 올린 예시 영상 목록과 재생. 영상은 지우지 않고 "숨기기"만 한다. 숨긴 영상도 이미 붙인 숙제에서는 계속 보인다. (HW-05)
- **T-17 숙제 제출 현황** — 숙제별로 학생의 제출 여부(미제출 / 제출됨). "숙제 체크"를 하는 화면이다. (HW-11)
- **T-18 제출 영상 피드백** — 학생의 연습 영상 재생, 학생이 적은 질문. 재생 중 원하는 시점에서 멈추고 코멘트를 단다. 텍스트 코멘트도 단다. 같은 숙제의 이전 제출로 넘겨 볼 수 있다. (HW-07, HW-10, HW-13)

### 결제·정산

- **T-19 환불 요청 목록** — 앱에서 온 환불 요청. 누르면 T-20으로 간다. (PAY-10)
- **T-20 환불 처리** — 대상 수강권, 남은 회차, 환불 처리 버튼. 앱 요청 없이 학생 상세(T-08)에서 바로 들어올 수도 있다. 금액 계산은 환불 규칙이 정해진 뒤 채운다. (PAY-09, PAY-11)
- **T-21 정산 내역** — 월별 정산 예정 금액, 차감된 회차 목록, 수수료, 지급 내역. (STL-02~05, STL-05는 제안)

### 채팅·내 정보

- **T-22 채팅** — 단체 채팅방과 1:1 대화(문의 포함)를 한 목록에서 본다. 단체 채팅방에는 관리자 기능이 더해진다: 메시지 가리기, 참여자 내보내기. 문의한 학생과의 대화에서 그 학생이 결제했는지 보인다. (CHAT-06, DM-01, DM-02)
- **T-24 내 후기** — 받은 후기 목록, 답글 달기(PRD 결정 필요 15), 후기 신고. (REV-03, REV-05, REV-06)
- **T-23 내 정보** — 프로필(T-03), 상품(T-04), 링크 공유(T-05), 받은 후기(T-24), 정산 계좌, 정산 내역(T-21), 설정(C-07).

## 5. 운영자 화면

운영자 기능은 앱 안(운영자 계정으로 로그인)과 별도의 웹 관리자 페이지 양쪽에 있다. (ADM-06) 기능은 같게 두고, 정산 현황과 신고 목록처럼 표가 긴 화면은 웹에서 먼저 만들고 앱에는 요약만 둔다.

- **A-01 트레이너 가입 신청 목록·상세** — 신청 정보(본인인증 결과, 정산 계좌, 프로필), 승인·거절. (ADM-01)
- **A-02 트레이너 목록** — 활동 중 / 정지 상태, 파일럿 여부. 누르면 A-05로 간다. (ADM-02, ADM-03)
- **A-05 트레이너 상세** — 트레이너의 모든 정보를 본다. 정지, 파일럿 지정·해제도 여기서 한다. (ADM-02, ADM-03, ADM-07, PLT-01)
  - 프로필·소개 영상, 레슨 상품, 그룹 반, 정산 계좌, 받은 후기
  - 학생 목록 → 학생별 수강권, 일정·출결, 숙제·제출 영상·피드백, 환불 내역 (트레이너 화면 T-07, T-08과 같은 내용을 읽기 전용으로)
  - 일정(목록·주간 캘린더), 정산 내역
- **A-03 신고 목록·처리** — 단체 채팅방·1:1 대화·후기 신고. 신고된 내용과 사유, 가리기, 사용자 이용 제한. 신고된 1:1 대화는 여기서 본다. (ADM-04)
- **A-04 정산 현황** — 트레이너별 월 정산 대상 금액과 지급 내역. (ADM-05 제안)

## 6. 상태에 따라 달라지는 표시

| 상황 | 표시 |
|---|---|
| 정기권 결제 후 트레이너가 일정을 입력하기 전 | 학생: 수강권 "일정 대기", 일정 목록 비어 있음. 트레이너: 홈에 "일정 입력 필요" |
| 레슨 시작 24시간 이내 | 학생 회차 상세의 취소 버튼 비활성, 안내 문구 |
| 수강권 1회 남음 | 학생 홈에 재결제 배너 |
| 수강권 종료(소진·만료·환불) | 수강권 "종료", 그 트레이너의 다른 수강권이 없으면 채팅방에서 나가짐 |
| 파일럿 트레이너 | 프로필에 상품·가격 대신 "시작하기", 결제 화면 없음, 정산 내역 없음 |
| 트레이너 승인 대기 | 프로필·상품 작성 가능, 링크 공유 불가 |
| 트레이너 정지 | 처리 방식이 정해진 뒤 정한다(`docs/prd.md` 결정 필요 3) |
| 본인인증 결과 만 19세 미만 | 가입 중단 안내 |

## 7. 결정 필요

1. **운영자의 학생 앱 사용** — 운영자 계정과 학생 계정을 따로 쓸지, 한 계정으로 둘 다 할 수 있게 할지. 제안은 따로 쓰는 것("한 계정은 한 역할" 규칙과 같게).
2. **학생 하단 탭** — 트레이너 찾기가 들어오면서 탭이 6개(홈·찾기·숙제·일정·채팅·내 정보)가 된다. 탭은 5개 이하가 쓰기 편하다. 제안: 숙제와 일정을 "레슨" 탭 하나로 합쳐 홈 · 찾기 · 레슨 · 채팅 · 내 정보로 한다. 레슨 탭 안에서 숙제 / 일정을 위쪽 탭으로 나눈다.
