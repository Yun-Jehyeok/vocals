# 보컬 레슨 플랫폼 — 아이디어 원문

## 원문

보컬 과외를 4년 정도 다니고 있는데, 불편한 점이 많고 있었으면 좋겠는 내용이 많아서 아래와 같은 여러 가지를 생각해 봤다.

1. "나만의 닥터", "amazing talker" 같은 플랫폼처럼 보컬 선생님 리스트업이 되어 있고, 그분들의 자기소개나 역량(영상 등)을 보고 선택해서 수업을 들을 수 있음.

2. 숙제를 플랫폼에서 확인할 수 있음. 예를 들어, 수업 시간에 비강에 조금 더 공기를 많이 보내라 라는 숙제를 내줬으면 이에 대해 선생님이 숙제를 플랫폼에 등록할 수 있고, 등록할 때 예시 동영상까지 같이 등록 가능. (실제로 보컬 학원들에서 숙제를 내줄 때, 오늘 한 거 잘 연습해 와라 정도이지 그날 연습한 걸 내 머릿속에 있는 것으로만 복습하고, 숙제를 해 와야 하는 문제가 있음. 이에 대해 실제로 내가 볼 수 있고, 참고하면서 숙제할 수 있는 게 필요함)

3. 어차피 보컬을 배우는 대부분은 기본기가 부족하고, 기본기부터 배워야 함. 그래서 기본기 마스터 클래스 같은 느낌으로, 기본기를 배울 수 있는 기능이 있으면 좋겠음. 예를 들면, 복식호흡을 배워야 한다면 내가 등록한 복식호흡 예시 영상과 설명을 보고, 이를 연습하고, 연습한 걸 영상으로 찍어 플랫폼에 연습 영상과 궁금한 점 등을 올리는 것. 그러면 그걸 보고 플랫폼에 등록된 많은 보컬 트레이너들이 댓글을 통해 첨언을 해 줄 수 있고, 그중 마음에 드는 트레이너에게는 학생이 트레이닝 등록도 할 수 있었으면 좋겠음. 거기에 트레이닝 등록은 사실 월 단위나 4회차 단위로 계산해야 하는데, 딱 복식호흡 하나만 배우고 싶을 수도 있음. 그러면 그에 대한 내용을 원격으로 비대면으로 배우고, 이에 대한 비용을 지불할 수 있게 하는 일회성 클래스도 있으면 좋겠음. (나중에 가능하다면 AI가 영상을 분석해서 피드백을 줄 수도 있겠지만 일단은 보류)

4. 위와 관련된 기본 기능들(예: 트레이너 등록/삭제, 로그인 등)은 다 있어야 하고, 추가로 레슨이 등록된 사람들에 대해 출결 체크, 숙제 체크 등도 있으면 좋겠음.

## 확정된 사항

- 모바일 우선으로 만들고, 웹은 나중에 만든다.
- 개발 순서
  1. 1단계: 레슨 관리 (숙제·예시 영상·출결) — 원문 2, 4번
  2. 2단계: 트레이너 마켓플레이스 + 결제 — 원문 1번, 3번의 일회성 클래스
  3. 3단계: 기본기 클래스 + 연습 영상 피드백 — 원문 3번
- AI 영상 분석 피드백은 보류한다.

## 결정 필요

PRD를 쓰기 전에 확인할 질문. ★ 표시는 1단계 데이터 모델에 영향을 주는 항목.

### 사용자·계정

1. ★ 1단계 트레이너는 개인 트레이너만 생각하나, 학원(여러 트레이너가 소속된 단위)도 지원하나?
2. ★ 한 학생이 여러 트레이너에게 동시에 배울 수 있나? 한 계정이 트레이너이면서 학생일 수도 있나?
3. 학생은 어떻게 합류하나? (트레이너가 보낸 초대 링크·코드, 트레이너가 직접 등록 등)
4. 로그인 방식은? (카카오, 애플, 구글, 전화번호 등)
5. ★ 미성년자 학생도 받나? 받는다면 보호자 동의나 보호자 계정이 필요한가?

### 레슨·출결·수강권

6. ★ 레슨은 1:1만인가, 그룹 레슨도 있나?
7. ★ 레슨 일정은 고정 반복(예: 매주 화요일 19시)인가, 매번 잡나? 일정 변경·취소는 누가 할 수 있나?
8. ★ 출결 상태는 어떤 것들이 있나? (출석, 지각, 결석, 사전 취소, 보강 등) 각 상태가 수강권을 차감하나? 차감 규칙을 트레이너마다 다르게 둘 수 있나?
9. ★ 수강권 유형: 월권은 "한 달 기간제"인가 "월 N회"인가? 4회권에 유효기간이 있나? 일회성 수업도 1단계에서 기록하나?
10. ★ 1단계 결제는 어떻게 처리하나? (플랫폼 밖에서 결제하고 트레이너가 "결제 완료"만 기록 / 결제 기록 없이 수강권만 관리 / 1단계부터 앱 안에서 결제)

### 숙제·영상

11. ★ 숙제는 특정 레슨 회차에 묶이나, 레슨과 별개로도 낼 수 있나?
12. ★ 예시 영상은 주로 어떻게 만들어지나? (수업 중 폰으로 찍어 바로 올림 / 미리 만들어 둔 영상 재사용) 같은 예시 영상을 여러 학생·숙제에 다시 쓰나?
13. 영상 대신 음성 녹음만 올리는 것도 허용하나? 영상 길이·용량 상한이 있나?
14. ★ 숙제 제출: 연습 영상·녹음 제출이 필수인가, "했어요" 체크만으로도 되나? 한 숙제에 여러 번 제출할 수 있나?
15. ★ 트레이너 피드백 형태: 텍스트만인가, 영상·음성 답장도 되나, 영상의 특정 시점에 코멘트를 다나?
16. 예시 영상과 연습 영상을 나란히 보는 기능을 1단계에 넣나?
17. 알림이 필요한 순간과 수단은? (숙제 등록, 마감 임박, 피드백 도착, 레슨 전날 / 푸시, 카카오 알림톡 등)

### 2·3단계 대비

18. ★ 트레이너 프로필 항목은 어디까지인가? (소개글, 소개 영상, 경력, 장르, 지역, 대면/비대면, 가격 등) 1단계부터 프로필을 입력받나?
19. ★ 2단계 결제 구조: 플랫폼이 결제를 받아 트레이너에게 정산하나(수수료), 트레이너가 직접 받나?
20. 2단계 일회성 비대면 클래스는 플랫폼 안에서 화상 레슨을 하나, 외부(Zoom 등) 링크로 하나?
21. ★ 3단계 연습 영상 공개 범위는? (전체 트레이너 / 지정한 트레이너 / 나만 보기) 1단계 숙제 영상(트레이너와 학생 사이)은 항상 비공개인가?

### 플랫폼·운영

22. 모바일 앱 형태: 스토어에 올리는 앱(네이티브·크로스플랫폼)인가, 홈 화면에 추가하는 웹앱(PWA)인가? iOS·Android 둘 다인가?
23. 첫 사용자(파일럿)는 지금 다니는 보컬 선생님인가? 그 밖에 테스트해 줄 트레이너가 있나?
24. 서비스 이름이 정해졌나?
